- In razor pages you can write code in html & C# and their extension is .cshtml
- You write C# code by using inline code like "@" before the C# code 
- if you need to write block of C# code use @{ C# code }

- to write literal text in C# block of code you can use @:literal or use Text html tag like <text> </text>

# Html.Raw()
  * is a method used to render unencoded HTML in your Razor views.
	It is useful when you need to output HTML markup directly.
	Use it cautiously, ensuring that any content rendered with it is free from malicious code.
